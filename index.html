About token security

This token is saved in your browser's local storage, which is not equivalent to secure server-side secret storage. Anyone with access to this browser/profile can read it. Use a fine-grained token restricted to this one repository with only the Contents permission, and revoke it from GitHub whenever you stop using this app.

Local Data

Exports exclude your GitHub token by default. Data lives only in this browser and does not sync across devices.
